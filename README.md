# 🏫 TDJSB — School Management System (ระบบบริหารจัดการโรงเรียน)

> **ระบบบริหารกิจการนักเรียนและงานบุคลากรโรงเรียน (TDJSB)**  
> พัฒนาขึ้นด้วย Native PHP + PDO MySQL/MariaDB ออกแบบรองรับการใช้งานผ่านมือถือ (Mobile-First / PWA Ready) พร้อมธีมใหม่ **Pastel Pink & Purple Glassmorphism**

---

## ✨ ฟังก์ชันหลัก (Core Features)

1. **ระบบบริหารจัดการนักเรียนและโฮมรูม (Homeroom & Attendance):**
   - เช็คชื่อเข้าแถวหน้าเสาธงแบบเรียลไทม์ (มา/สาย/ลา/ขาด)
   - สแกนบัตรนักเรียนด้วย QR Code / กล้องมือถือ
   - ระบบสลับเช็คชื่อละหมาดวันศุกร์ (เปิด/ปิดได้จากศูนย์ตั้งค่า)
   - สรุปสถิติและรายงานประจำเดือนส่งฝ่ายกิจการนักเรียน

2. **ระบบงานบุคลากรและลงเวลาปฏิบัติงาน (Teacher Attendance with GPS):**
   - ลงเวลาปฏิบัติงานด้วยการถ่ายรูปเซลฟี่ + ปั๊มลายน้ำพิกัด GPS อัตโนมัติ
   - ตรวจสอบรัศมีระยะห่างจากศูนย์กลางโรงเรียนแบบไดนามิก
   - ระบบส่งรายงานการปฏิบัติงานและชั่วโมงสอน

3. **ระบบกิจการนักเรียนและวินัย (Discipline & Behavior Tracking):**
   - บันทึกคดีและพฤติกรรม พร้อมแนบหลักฐานภาพถ่าย
   - ระบบตัด/เพิ่มคะแนนความประพฤติ (เริ่มต้น 100 คะแนนอัตโนมัติ)
   - ออกรายงาน PDF และบัตรประจำตัวนักเรียน

4. **การนำเข้าข้อมูลโรงเรียน (Data Onboarding):**
   - รองรับไฟล์ Excel / CSV จากระบบมาตรฐานการศึกษาไทย (**DMC / SGS**)
   - ระบบ Auto-Encoding (Windows-874 / TIS-620 $\rightarrow$ UTF-8) ป้องกันภาษาต่างด้าว
   - ตรวจจับคำนำหน้าชื่อเพื่อระบุเพศอัตโนมัติ และเติมเลขศูนย์นำหน้ารหัสนักเรียน

5. **ศูนย์ควบคุมโรงเรียน (Dynamic School Customization):**
   - ตั้งชื่อโรงเรียน, อัปโหลดโลโก้, ปักหมุด GPS, กำหนดรัศมีลงเวลา และเวลาตัดสายผ่านหน้าเว็บ (`admin_web_management.php`) โดยไม่ต้องแก้ไขโค้ด

## 🛠️ ความต้องการของระบบ (Requirements)

* **PHP:** 7.4 ขึ้นไป (รองรับ PHP 8.0, 8.1, 8.2, 8.3)
* **Extensions:** `pdo_mysql`, `mbstring`, `gd`, `zip`
* **Database:** MySQL 5.7+ หรือ MariaDB 10.3+
* **Web Server:** Apache (พร้อม `mod_rewrite`) หรือ Nginx

## 🚀 ขั้นตอนการติดตั้ง (Quick Start)

### 1. โคลน Repository
```bash
git clone https://github.com/<YOUR_USERNAME>/<YOUR_REPOSITORY>.git
cd <YOUR_REPOSITORY>
```

### 2. ตั้งค่าการเชื่อมต่อฐานข้อมูล
คัดลอกไฟล์ตัวอย่างการตั้งค่าฐานข้อมูล:
```bash
cp config/database.php.example config/database.php
```
จากนั้นแก้ไขข้อมูล `$db_host`, `$db_name`, `$db_user`, `$db_pass` ในไฟล์ `config/database.php` ให้ตรงกับฐานข้อมูลของคุณ

### 3. ติดตั้งฐานข้อมูล (เลือกได้ 2 วิธี)
* **วิธีที่ 1 (ผ่านเว็บเบราว์เซอร์ - ง่ายที่สุด):**  
  เปิดเบราว์เซอร์ไปที่: `https://your-domain.com/database/init.php`  
  *(เมื่อติดตั้งเสร็จแล้ว ให้ลบหรือเปลี่ยนชื่อไฟล์ `database/init.php` เพื่อความปลอดภัย)*
* **วิธีที่ 2 (ผ่าน phpMyAdmin / Terminal):**  
  นำเข้าไฟล์ `database/schema.sql` เข้าสู่ฐานข้อมูล

### 4. สิทธิ์ของโฟลเดอร์สำหรับอัปโหลดไฟล์
กำหนดสิทธิ์ให้เว็บเซิร์ฟเวอร์สามารถเขียนไฟล์ลงใน `assets/uploads/`:
```bash
chmod -R 755 assets/uploads/
```

## 📁 โครงสร้างโปรเจกต์ (Clean Architecture)

```text
TDJSB/
├── assets/
│   ├── css/                  # สไตล์ชีท (liquid-glass.css, style.css)
│   ├── js/                   # สคริปต์สแกนเนอร์, QR Code, HTML2PDF
│   ├── images/               # โลโก้และภาพกราฟิกพื้นฐาน
│   └── uploads/              # โฟลเดอร์จัดเก็บรูปภาพตามหมวดหมู่ (PDPA Clean)
├── config/
│   ├── database.php.example  # ตัวอย่างไฟล์เชื่อมต่อฐานข้อมูล
│   └── auth.php              # ฟังก์ชันตรวจสอบสิทธิ์และเซสชัน
├── database/
│   ├── init.php              # สคริปต์ติดตั้งระบบฐานข้อมูลผ่านเว็บ
│   └── schema.sql            # โครงสร้างฐานข้อมูลสะอาด 31 ตาราง
├── includes/
│   ├── header.php            # เมนูหลักด้านบน, ดึงค่า site_settings
│   ├── footer.php            # สคริปต์ปิดท้ายหน้าเว็บ
│   ├── sidebar.php           # เมนูด้านข้างตามสิทธิ์ของผู้ใช้งาน
│   └── bottom_nav.php        # เมนูการนำทางด้านล่างสำหรับสมาร์ตโฟน
├── src/actions/              # โมดูลฟังก์ชันระบบงานทั้งหมด (Admin, Teacher, ฯลฯ)
├── index.php                 # หน้าแรกและหน้าเข้าสู่ระบบ (ธีมพาสเทล)
└── manifest.json             # ตั้งค่าเว็บแอปพลิเคชันมือถือ (PWA)
```
